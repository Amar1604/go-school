# 🏫 School ERP System

A full-stack *School ERP (Enterprise Resource Planning)* system designed to digitize and streamline school operations. This platform serves students, teachers, and administrators with features like fee payments, attendance tracking, online classes, exam management, and more.

---

## ✨ Features

### 👨‍🎓 For Students:
- ✅ Request and track bus services
- 💳 Pay school fees online
- 📝 View and submit assignments
- 🖥 Join online classes
- 📆 Check exam schedules and results

### 👩‍🏫 For Teachers:
- 📋 Upload and manage student attendance
- 🧪 Conduct and grade exams
- 📚 Assign homework and class materials
- 🎥 Schedule and run online classes
